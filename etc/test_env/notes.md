Execution of a blink program generated by STM32 HAL:

main function:

  Call HAL_INIT():
    This function does the following -
    1. Initializes Flash Prefetch
    2. Initializes the systick timer
    3. Initializes low-level hardware (not actuall implemented in our case)


    1. Initializes Flash Prefetch
    note that this is implemented as a constant define, and is thus stored in ROM
    it is executed after our main function is executed, thus the notion of 'prefetch' is questionable, if not executed before (1)
    Call HAL_FLASH_PREFETCH_BUFFER_ENABLE():
      FLASH->ACR |= FLASH_ACR_PRFTBE
    
    2. Initializes the Systick Timer
    Call HAL_InitTick(TICK_INT_PRIORITY): 
      Configures the quantized time delta for system tick 1 ms by default
      It is important that interrupts are configured with higher priority to systick

      Call HAL_SYSTICK_Config: SystemCoreClock / (1000U / uwTickFreq)) > 0U

        Call SysTick_Config: ticks (passed number above)
          Initializes System Timer and its interrupt, and starts the System Tick Timer
          Passed the number of ticks between interrupts

          SysTick->LOAD = (ticks - 1)
          NVIC_SetPriority(SysTick_IRQn, (1 << __NVIC_PRIO_BITS) - 1)
          SysTick->VAL = 0
          SysTick->CTRL = CTRL_CLKSOURCE_MSK | CTRL_TICKINT_MSK | CTRL_ENABLE_MSK

          Call NVIC_SetPriority: IRQn, priority
            if ((int32_t)(IRQn) >= 0)
            {
              NVIC->IP[_IP_IDX(IRQn)]  = ((uint32_t)(NVIC->IP[_IP_IDX(IRQn)]  & ~(0xFFUL << _BIT_SHIFT(IRQn))) |
             (((priority << (8U - __NVIC_PRIO_BITS)) & (uint32_t)0xFFUL) << _BIT_SHIFT(IRQn)));
            }
            else
            {
              SCB->SHP[_SHP_IDX(IRQn)] = ((uint32_t)(SCB->SHP[_SHP_IDX(IRQn)] & ~(0xFFUL << _BIT_SHIFT(IRQn))) |
             (((priority << (8U - __NVIC_PRIO_BITS)) & (uint32_t)0xFFUL) << _BIT_SHIFT(IRQn)));
            }

      Call HAL_NVIC_SetPriority: SysTick_IRQn, TickPriority, 0
        assert IS_NVIC_PREEMPTION_PRIORITY(TickPriority)
        NVIC_SetPriority(IRQn, TickPriority) // believe this is also done before hmmm

      set uwTickPrio = TickPriority (TICK_INT_PRIORITY)

    3. Initializes low-lever hardware
    Call HAL_MspInit:
    weak function, not implemented, intended to initialize low level hardware
